🧪 水溶液的奧秘・互動科學數位實驗室大廳

歡迎來到小小化學家互動實驗室！在這裡，你可以親自動手吸取生活中的水溶液、操作石蕊試紙與高麗菜汁變色，還能調配水溶液探索酸鹼中和！

🧪 實驗模式一

實驗一：水溶液的酸鹼性與指示劑

探索生活中常見的 7 種水溶液（檸檬汁、小蘇打水、白醋、肥皂水等），使用擬真玻璃滴管在紅藍石蕊試紙、廣用試紙與紫色高麗菜汁上自由滴落，觀察真實細膩的變色反應！

✓ 石蕊試紙自由落點滴落與毛細暈染動畫
✓ 廣用試紙 pH 1~14 標準比色卡即時高亮
✓ 紫色高麗菜汁原液對照組 vs 實驗組
✓ 7 種水溶液自主判斷通關 + 8 題觀念考考你
進入「指示劑實驗室」 🚀
⚗️ 實驗模式二

實驗二：水溶液混合與酸鹼中和

酸與鹼混合後性質會如何改變？親自吸取不同強度的酸性與鹼性水溶液滴入混合燒瓶中，觀察指示劑顏色連續漸變，並透過放大版石蕊試紙進行即時採樣檢驗！

✓ 符合物理化學嚴格上下限定律的混合反應引擎
✓ 反應燒瓶液面動態上升 + 磁力攪拌器轉動動畫
✓ 【重點升級】放大版紅石蕊、藍石蕊、廣用試紙採樣工作台
✓ 4 大中和自主任務挑戰 + 10 題生活情境考考你
進入「水溶液混合實驗室」 🚀
⚡ 實驗模式三

實驗三：水溶液的導電性

挑選必備器材組裝檢測電路，放入正負極檢測棒測試純水、自來水、食鹽水、糖水等是否導電，觀察 LED 燈泡發光與電流通路，並對照生活用電安全！

✓ 前置準備：動手挑選必備器材與干擾物件辨別
✓ 關鍵對照：純水（不導電）vs 自來水（能導電）
✓ 正負極升降檢測 + LED 燈泡發光 + 通路電流流動
✓ 7 種溶液實驗觀察紀錄表 + 8 題情境考考你
進入「導電性實驗室」 🚀

教師教學與學生離線下載操作指引

📦 1. 整包打包下載

建議將整個資料夾（包含 index.html、aqueous_acid_base_lab.html、aqueous_mixing_lab.html 與 aqueous_conductivity_lab.html）打包為 ZIP 壓縮檔發送給學生。

⚡ 2. 零設定・雙擊即開

所有超連結均使用純相對路徑，完全不需要架設伺服器。學生解壓縮後，只要雙擊開啟 index.html，即可在無網路環境下順暢跳轉與離線操作！

💻 3. 跨載具自適應

支援電腦教室桌機、小筆電、iPad、Chromebook 或手機。純原生 JavaScript 與內嵌 SVG 插畫，不依賴任何外部圖檔，載入極速且觸控友善。
